# Security reporting

Report suspected credential exposure, unauthorized access to private tables or cards, ledger tampering, or unsafe deployment behavior privately. Use the repository's GitHub private vulnerability reporting if available; otherwise contact a maintainer through a private channel. Do not open a public issue with sensitive details.

Include the affected commit or image version, the deployment mode, the impact, and steps to reproduce using fake accounts or a disposable local database. Do not attach credentials, live invite links, session cookies, backups, or logs that contain player or settlement data. If a credential was exposed, tell the operator so they can revoke or rotate it.

For deployment and recovery, see the [operator guide](docs/operator.md).
